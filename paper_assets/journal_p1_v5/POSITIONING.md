# Positioning for the Journal of Global Optimization

For a prescribed set of outer radii, minimizing the radius of a common tangent circle requires choosing both a cyclic order and a placement. This paper gives exact-width rational brackets for the global infimum for each size from 3 through 14. A verifier certifies the lower bound by covering all cyclic orders with angular inequalities and integer dynamic programming. Rational Cartesian witnesses establish the upper bound. The anti-Monge structure of the angular kernel also identifies a tractable relaxation and a single seam condition explains when that relaxation is geometrically exact. These results connect verified packing optimization with discrete order structure, and the accompanying data let a reader replay the complete finite proof.
