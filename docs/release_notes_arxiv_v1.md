# v1.0-arxiv-v1 — arXiv v1 published

The paper *Arranging circles of radii 1,2,...,n around a central circle: a Supnick TSP and certified finite optima* is now public as [arXiv:2607.28654](https://arxiv.org/abs/2607.28654) [cs.CG].

This release records the repository state associated with arXiv v1. It includes:

- the paper source and PDF;
- certified optima for `n = 3,...,14`;
- the independent verifier; and
- the certificate artifacts supporting the certified finite results.

This post-publication metadata and documentation pass does not change any certified result under `results/`.
